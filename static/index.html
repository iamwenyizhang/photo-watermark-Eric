3. 预览

上传照片后此处显示水印预览，点击文件列表可切换预览对象

4. 批量处理

输出为「原名_水印.jpg」，保存到工具目录下的 output 文件夹，原图不修改，EXIF 信息完整保留。社交卡片 / 模糊背景 / 品牌留白模板会扩展画布，输出尺寸大于原图。
